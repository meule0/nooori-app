# 눌이 (Nooori) 안드로이드 앱

눌이 모바일 앱의 **APK 배포 전용** 공개 저장소입니다. 여기에는 APK 바이너리와 릴리스 노트만 올라갑니다.

## 앱 설치 (안드로이드)

1. **[최신 APK 다운로드](https://github.com/meule0/nooori-app/releases/latest)** → Release 페이지의 `.apk` 파일 선택
2. 다운로드한 APK를 열어 설치
3. Google Play Protect 경고가 뜨면 **"위험 무시하고 설치"** 선택 (스토어를 거치지 않은 APK라 표시됩니다)

앱 ID: `xyz.nooori.app`

## 업데이트

- 화면·기능 수정은 앱이 켜질 때 **OTA(Expo Update)**로 자동 반영됩니다. 재설치가 필요 없습니다.
- 네이티브 변경(권한·라이브러리)이 포함된 업데이트는 새 Release로 배포됩니다. 앱이 안내하면 최신 APK를 다시 설치해 주세요.

## 버전

각 [Release](https://github.com/meule0/nooori-app/releases)의 태그(`v1.0.0` 등)가 앱 버전입니다.
